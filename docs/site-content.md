# 公開ページの文面（Googleサイト貼り付け用）

App Store Connect には「プライバシーポリシーURL」と「サポートURL」の登録が必須で、
どちらも**ログインなしで誰でも開ける**必要がある。

GitHub Pages ではなく Googleサイトで公開する。App Store Connect に
`github.io` のURLを載せるとソースの所在が分かってしまうため。

問い合わせ窓口はメールアドレスを公開せず、**Googleフォーム**で受ける。

以下はそのまま貼り付けられる本文。HTMLタグは使わず、Googleサイトの見出し機能で
「■」の行を見出しにすればよい。

作業順序は **フォーム → サイト → 未ログイン確認** の3手順（後述）。

このアプリは**完全無料**（App内課金・広告・サブスクリプションなし）。
英単語アプリの文面から課金に関する記述をすべて落としてある。

## ページ3: サポート

ページのURLパスは `support`（アプリに埋め込み済み。**変更しないこと**）。

見出し（大）:

```
サポート
```

本文:

```
大学受験の古文に必要な単語と文法を、通信なし・広告なしで学習するアプリです。
単語帳・4択クイズ・聞き流しを、すべて端末内で完結して使えます。

■ 料金について
完全無料です。App内課金、月額・年額の課金、広告のいずれもありません。
収録している314語・80項目・125問のすべてを、最初からご利用いただけます。
機能が制限される期間や範囲もありません。

■ 収録内容
・古文単語 314語
・古典文法 80項目（助動詞28／助詞20／敬語16／識別・その他16）
・文法の4択問題 125問

■ 学習の記録は他の端末に引き継げますか？
いいえ。本アプリは通信を行わず、学習履歴を端末内にのみ保存する設計のため、
端末間での同期はできません。アプリを削除すると履歴も消えます。

■ 「覚えた」はどうすれば付きますか？
直前に正解しただけでは付きません。正解するたびに復習の間隔が
1日 → 3日 → 7日 → 14日 → 30日 と伸び、7日以上の間隔に到達した項目が「覚えた」になります。
翌日には忘れている項目を「覚えた」に数えないための設計です。
間違えると間隔は最短に戻ります。

■ 「覚えた」が減ることがあります
仕様です。復習の期限が来た項目は「要復習」に戻ります。
忘却を無視して数字だけが増え続ける表示は学習の役に立たない、という考えによるものです。

■ 文法項目の習熟度はどう決まりますか？
その項目に紐づく4択問題の成績から決まります。
1問でも「要復習」があれば項目全体が「要復習」、すべてが「覚えた」に達したときだけ
「覚えた」になります。解ける問題が残っているうちに「覚えた」と表示しないためです。

■ 画面を消しても聞き流しは続きますか？
続きます。イヤホンやスピーカーで再生したまま画面をロックしても止まりません。
ロック画面から再生・停止・曲送りの操作もできます。

■ 読み上げの音が見出し語と違います
仕様です。見出し語は歴史的仮名遣いで表記し（例「あはれなり」）、
読み上げは現代仮名遣いの音で行います（例「あわれなり」）。
実際の発音に合わせるためで、単語詳細では両方をご確認いただけます。

■ 特定の範囲だけ学習したい
4択クイズと聞き流しの画面上部で、「すべて／未学習／要復習／学習中／覚えた」を
切り替えられます。「要復習だけ解き直す」といった使い方ができます。

■ 収録内容の意味や例文に誤りを見つけました
下記のお問い合わせフォームからお知らせください。アップデートで修正します。
データを更新しても、学習履歴は保持される設計になっています。

■ お問い合わせ
不具合のご報告・ご要望・収録内容の誤りのご指摘は、下記のフォームからお願いします。

お問い合わせフォーム
（フォームのURL）

Googleアカウントへのログインは不要です。
ご返信をご希望の場合は、フォーム内の「返信先メールアドレス」欄にご入力ください。
空欄のままでもご送信いただけます（その場合、個別のご返信はできません）。
ご返信には数日いただく場合があります。
```

> 貼り付けたあと、`お問い合わせフォーム` の行を選択して Googleサイトのリンク機能
> （ツールバーのリンクアイコン）でフォームのURLを設定し、`（フォームのURL）` の行は
> 削除する。URLをそのまま本文に残しておいても動作はする。

## 手順1: Googleフォームを先に作る

サポートページの本文にフォームのURLを貼るため、**フォームを先に作る**。

### フォームのタイトルと説明

タイトル:

```
高校古文 単語・文法特訓 お問い合わせ
```

説明:

```
不具合のご報告、ご要望、収録内容の誤りのご指摘をお送りいただけます。
Googleアカウントへのログインは不要です。
ご返信をご希望の場合のみ、最後の欄にメールアドレスをご入力ください。
```

### 質問項目

| # | 質問 | 形式 | 必須 | 選択肢・補足説明 |
| --- | --- | --- | --- | --- |
| 1 | お問い合わせの種類 | ラジオボタン | ○ | 不具合の報告 / 単語・文法の内容の誤り / ご要望・改善提案 / その他 |
| 2 | 内容 | 段落 | ○ | 補足説明: どの画面で、どのような操作をしたときに起きたかをお書きいただけると助かります。 |
| 3 | 該当する単語・文法項目・画面 | 記述式 | — | 補足説明: 内容の誤りのご指摘の場合は、該当する単語や文法項目をご記入ください。 |
| 4 | ご利用のiOSバージョン | 記述式 | — | 補足説明: 「設定」→「一般」→「情報」→「iOSバージョン」で確認できます。 |
| 5 | 返信先メールアドレス | 記述式 | — | 補足説明: ご返信が不要な場合は空欄で構いません。ご返信以外の目的には使用しません。 |

質問5は**必須にしない**。必須にすると、報告だけしたい人が名乗らないと送信できなくなる。

英単語アプリのフォームにあった「購入・復元について」の選択肢は入れない（課金が無いため）。

### 設定タブ（ここを間違えると審査で差し戻される）

- **「回答」→「メールアドレスを収集する」を「収集しない」にする**
  - 既定が「確認済み」になっていることがある。これだと**Googleアカウントへのログインが必須**になり、
    ログインしない審査担当者はフォームを開けない
  - 返信先は質問5（任意の記述式）で受けるので、この機能は使わない
- **「回答」→「ログインを必須にする」「1回に制限する」をオフにする**（同じ理由）
- 「回答」→「回答のコピーを回答者に送信」はオフのままでよい
- **「全般」→「新しい回答についてメール通知を受け取る」をオンにする**
  - `chicktack0321@gmail.com` に届く。ここをオフにすると問い合わせに気づけない

### URLの取得

右上「送信」→ リンクのアイコン（🔗）→ URLをコピーする。
`https://forms.gle/...` の短縮URLで問題ない。これをサポートページに貼る。

## 手順2: Googleサイトを作る

1. https://sites.google.com を開き、**空白のサイト**を作成する
2. サイト名を「高校古文 単語・文法特訓」にする
3. 右のメニュー →「ページ」から `プライバシーポリシー` と `サポート` を追加する
4. 各ページの右クリック →「プロパティ」で**URLパスを `privacy-policy` / `support` に変更**する
5. 上の本文を貼り付ける（「■」で始まる行は見出しにすると読みやすい）
6. 右上「公開」→ **ウェブアドレスを `kobun-tokkun` にする**
7. **公開設定で「閲覧できるユーザー」を「公開（ウェブ上の全員）」にする**

### 手順6のウェブアドレスは変更できない前提で決める

`KobunApp/Common/AppConfig.swift` に次のURLを埋め込み済み。ここを変えるとアプリ内の
リンクが切れ、直すには再ビルドと再提出が必要になる。

- `https://sites.google.com/view/kobun-tokkun/privacy-policy`
- `https://sites.google.com/view/kobun-tokkun/support`

`kobun-tokkun` が他の人に使われていて取れない場合は、**サイトを作る前に**別の名前を決め、
`AppConfig.swift` を先に直してからビルドし直すこと。

### 手順7が最重要

ここを既定のままにすると、**ログインしないと開けないページ**になる。
審査担当者はログインできないので、URLが開けないという理由で差し戻される。

**フォームの公開設定はサイトの公開設定とは別管理**である点にも注意する。
サイトを「ウェブ上の全員」にしても、フォーム側でログインが必須になっていれば、
審査担当者はサポートページからフォームへ進んだところで止まる。

## 手順3: シークレットウィンドウで3つとも確認する

公開後、**シークレットウィンドウ（ログインしていない状態）**で次の3つを開く。
ここだけは必ず自分の目で見ておく。

1. プライバシーポリシーのページが開けるか
2. サポートのページが開けるか
3. サポートページのリンクから**フォームが開けるか**

さらに、シークレットウィンドウのまま**実際に1件送信してみる**。

- メールアドレス欄を空欄のままでも送信できること
- `chicktack0321@gmail.com` に通知メールが届くこと

## 注意点

- **サポートページにメールアドレスは書かない**。利用者向けの公開窓口はフォームのみ
- ただし **App Store Connect の「サポート連絡先」欄にはメールアドレスの入力が必須**。
  こちらは Apple と審査担当者しか見ない非公開情報なので `chicktack0321@gmail.com`
  を入れてよい。利用者に公開されるものではない
- App Store Connect のプライバシー申告は「データを収集しません」でよい。
  申告の対象はアプリ本体であり、アプリ外のサポートサイトやフォームは含まれない
- 価格は **無料**。App内課金は登録しない
- Googleサイトの独自ドメインは任意。`sites.google.com/view/...` のままでよい
- 公開後にページを編集した場合、**再度「公開」を押さないと反映されない**
- フォームを編集した場合は自動で反映される（公開ボタンはない）が、
  質問を消すとそれまでの回答も見えなくなる点に注意
